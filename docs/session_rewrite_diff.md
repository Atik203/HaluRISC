- OLD L271 [284w]: Large language models answer fluently, but some answers are not supported by the evidence. Detectors based on a large judge model, an encoder, or model internals are expensive and rarely report calibration under domain or task shift. Feature-based detectors can be cheaper. Their calibration and sensitivity to answer length are usually not analyzed together. This work investigates whether a simple feature model can predict hallucination risk and how its ranking and calibration are affected by shift. This work introduces EC-XGB, an evidence-consistent XGBoost model with base features, claim-level natural language inference (NLI) aggregate scores, and a source indicator. Split conformal prediction reaches 0.944 coverage at 90\%, with only 0.685 positive coverage. A contradiction decides only if no sentence supports the claim and a sentence has a contradiction probability of at least 0.5 that is higher than its entailment probability. As shown in Figures~\ref{fig:pipeline} and~\ref{fig:system}, the process of generating a score for an individual answer consists of calling the appropriate model or function in either the client or server side based on the type of input used for that particular question.

For HaluBench, the number of PASS and FAIL answers by source in each length bucket remained unchanged. Only pairs of answers whose difference in length was very small were chosen for the MedHallu test set. Pairing resulted in a drop of 1.5 AUROC points for HaluBench and 4.7 for MedHallu, as well as a drop in pair accuracy from 0.8607 to 0.8290. Despite the drop in accuracy, both sources still outperformed a simple length-only baseline, at 0.588 versus 0.475 for HaluBench and 0.771 versus 0.401 for MedHallu. The performance on HaluBench was only slightly better than random chance, which suggests that transferability is far from robust however much pairing may help.
